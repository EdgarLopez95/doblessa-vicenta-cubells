# Doblessa — Dra. Vicenta Cubells

Mockup estático del rediseño de la Dra. Vicenta Cubells. La investigación y recursos aprobados están en `../Recursos/` dentro de la carpeta madre.

## Desarrollo

```bash
npm install
npm run dev
npm run build
```

Cada push a `main` publica el sitio automáticamente.

- Repositorio: `https://github.com/EdgarLopez95/doblessa-vicenta-cubells`
- Presentación: `https://edgarlopez95.github.io/doblessa-vicenta-cubells/`

Antes de trabajar, leer `AGENTS.md` y `ESTADO.md`. Para entregar: `git status`, `git add <archivos>`, `git commit -m "feat: descripcion breve"` y `git push origin main`. No usar `git push --force` ni modificar `../Recursos/`.
